# Yomira v7.1.0-Beta

Android versionCode: **13**.

- Removed chapter download buttons for an ultra-clean, lightweight reader UI.
- **ContentRatingClassifier 2.0:** rule-based Vault filtering moves Tsugumomo, Carrier's Strategy, and Yabadere out of Vault and into the Home catalog.
- Read chapters dim to **38% opacity (0.38f)**, with an unread-only chapter filter.
- **True Global Consensus Popularity:** logarithmic popularity ranking prioritizes global hits such as Solo Leveling and One Piece.
- **Adaptive Evolutionary Home Feed:** Dynamic Shelf Promotion replaces random dice rolls.
- **Four-step Onboarding Survey & Global Blacklist:** hide Futanari, Yaoi, Yuri, NTR, and Gore, with a Settings editor for subsequent changes.
- **Smart Source Matcher 2.0:** Romaji and English multi-query matching, token containment, and graceful fallback.

See `VALIDATION_v7.1.0-Beta.md` for build and connected-device verification results and limitations.
